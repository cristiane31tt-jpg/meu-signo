Meu Signo Astrologia, signos e compatibilidade

Política de Privacidade

Última atualização: 10 de outubro de 2026.

Esta política explica, de forma simples, como o aplicativo Meu Signo trata as informações de quem o utiliza. Resumo: o app funciona sem conta, sem login e sem enviar os seus dados para servidores. Tudo o que você informa permanece apenas no seu próprio aparelho.

1. Quem é o responsável

O aplicativo Meu Signo é desenvolvido e mantido por Cristiane Alves Sousa, que é o controlador dos dados aqui descritos.

Contato para assuntos de privacidade: minimonkeyoficial@gmail.com.

2. Quais dados são tratados

O Meu Signo não solicita nome, e-mail, telefone, localização, contatos, fotos nem qualquer identificação pessoal. Os únicos dados envolvidos são:

  • Data de nascimento — informada por você, e usada apenas para calcular o seu signo. Ela é guardada no seu aparelho para preencher o campo na próxima vez.
  • Preferências de exibição — pequenos registros técnicos que controlam qual variação de texto e qual frase foram mostradas por último, para não repetir o mesmo conteúdo em acessos seguidos.

Não são coletados dados sensíveis, dados de saúde, identificadores de publicidade, dados de localização, nem informações de uso analítico.

3. Para que os dados são usados

  • Calcular e exibir o seu signo com base na data informada.
  • Mostrar a compatibilidade entre signos quando você pede.
  • Lembrar a última data informada para facilitar um novo acesso.
  • Alternar as variações de texto e frases entre visitas.

Nenhum desses dados é utilizado para publicidade, perfilamento, venda ou compartilhamento de qualquer natureza.

4. Onde e como ficam armazenados

Todo o armazenamento é local, feito pelo próprio navegador do seu aparelho. O app não possui banco de dados remoto nem servidor próprio.

Chave de armazenamento Tipo O que guarda Duração
meu-signo:last-date localStorage A última data de nascimento informada, para preencher o campo. Até você limpar os dados do navegador.
meu-signo:bag:* sessionStorage Controle de rotação de frases e variações dentro da sessão. Apagada ao fechar a aba ou o app.
meu-signo:last:* localStorage Índice (apenas número) do último texto exibido, para evitar repetição imediata. Até você limpar os dados do navegador.

Esses registros não saem do seu aparelho. Eles não contêm nenhuma identificação pessoal além da data de nascimento que você mesma informou.

5. Compartilhamento de dados

O Meu Signo não compartilha, não vende e não transfere seus dados a terceiros. Não há envio de informações para servidores externos, pois o aplicativo não realiza requisições de rede para esse fim.

6. Serviços de terceiros, publicidade e analytics

  • Não há bibliotecas de anúncios.
  • Não há ferramentas de análise (analytics) ou rastreamento.
  • Não há integração com redes sociais, login externo ou pagamentos.
  • Não há cookies próprios nem de terceiros.

Quando o site é acessado pela internet (por exemplo, hospedado no GitHub Pages), o provedor de hospedagem pode registrar informações técnicas padrão do pedido, como o endereço IP, para operar e proteger o serviço. Esse registro é próprio da hospedagem, não é controlado nem utilizado pelo Meu Signo e não é acessado pelo aplicativo.

7. Cookies

O aplicativo não utiliza cookies. As informações de que trata a seção 4 ficam no armazenamento local do navegador (localStorage e sessionStorage), que é diferente de cookies e não é enviado a nenhum servidor.

8. Segurança

Como os dados permanecem apenas no seu aparelho, a proteção está ligada à segurança do próprio dispositivo e do navegador. Recomendamos manter o sistema atualizado e usar bloqueio de tela.

O aplicativo é composto por arquivos estáticos executados localmente. Não há transmissão de dados pessoais que possa ser interceptada, porque não há envio.

9. Por quanto tempo os dados ficam guardados

Os dados ficam no aparelho até que você os apague. Você pode removê-los a qualquer momento:

  • limpando os dados de navegação do navegador/aplicativo; ou
  • desinstalando o aplicativo, quando instalado como app.

10. Seus direitos

Nos termos da Lei Geral de Proteção de Dados (LGPD, Lei nº 13.709/2018), você pode solicitar confirmação, acesso, correção, portabilidade e eliminação dos seus dados, além de se opor a tratamentos indevidos.

Como o Meu Signo não mantém dados em servidores nem identifica usuários, essas informações já estão sob o seu controle no próprio aparelho. Ainda assim, dúvidas e solicitações podem ser enviadas para minimonkeyoficial@gmail.com.

11. Crianças e adolescentes

O Meu Signo é um aplicativo de entretenimento sobre signos, adequado ao público geral. Ele não coleta dados pessoais e, por isso, não trata intencionalmente informações de crianças ou adolescentes.

12. Alterações nesta política

Esta política pode ser atualizada para refletir melhorias no aplicativo ou mudanças na legislação. A versão vigente é sempre a publicada nesta página, com a data de atualização indicada no topo.
